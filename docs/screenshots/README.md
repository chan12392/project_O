# 화면 캡처 (2026-11-02)

브라우저 미리보기(`npm run dev`, `?source=demo`)에서 이 PC의 실제 O 실행 기록을 경로만 바꿔 재생한 화면이다. 1600×1000. 모두 Antigravity 실행 보류([ADR-0020](../decisions/0020-antigravity-policy.md)) 전 화면이다. 일부 화면에 Antigravity 카드 실행이 보인다.

| 파일 | 장면 |
|---|---|
| `01-overview.png` | 전체 작업 환경. 왼쪽 프로젝트 목록, 가운데 총괄 채팅(요청 → 카드 3장 진행), 오른쪽 사무실과 사용량 |
| `02-lead-command.png` | 총괄에게 새 일을 맡기는 순간. 이전 요청과 총괄의 분배 보고 아래 입력창에 다음 지시 |
| `03-lead-working.png` | 총괄이 지휘하는 중. 채팅의 작업 카드 진행과 에이전트 작업 탭 대시보드 |
| `04-office-team.png` | 사무실. 카드마다 한 사람이 자기 책상에서 일하고 팀 대화(`o msg`)로 말을 주고받음 |
| `05-office-closeup.png` | 사무실 패널 확대. 완료 상자, 말풍선, 한 줄 사용량(5시간·주간 한도 고리) |
| `06-dashboard.png` | 대시보드. 기다리는 일 티켓 → 현황 → 작업 흐름 → 활동 |
| `07-next-up.png` | 다음 할 일. 다음 할 일 / 멈춘 작업 두 줄 |
| `08-board.png` | 보드. 카드 칸반(대기·작업 중·PR·완료·막힘) |
| `09-projects-and-status.png` | 그룹으로 묶은 프로젝트 목록과 채팅 머리글의 "지금 누가 무엇을" 팝업 |
| `10-architecture.png` | 아키텍처 한 장 (원본 `architecture.html`) |

다시 찍을 때: 개발 서버를 띄우고 같은 주소(`?source=demo&run=…&view=…&t=…`)를 1600×1000으로 찍는다. 실시간 모드(`source=live`) 화면은 실제 폴더 경로가 보이므로 공유용 캡처에 쓰지 않는다.

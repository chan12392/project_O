project_O 아키텍처

총괄 에이전트가 일을 작업카드로 나누고, O CLI가 공식 에이전트 CLI들에 병렬로 맡기고, 앱은 그 기록만 읽어 채팅·사무실·대시보드로 보여 준다.

사람

대표님

프로젝트 총괄에게 자연어로 요청한다.

  • "코딩은 Codex, 디자인은 Antigravity로"
  • 모델·노력 수준은 사람이 고른다
  • 역할 이름은 자유 라벨 (모델을 강제하지 않음)
→
프로젝트마다 하나

총괄 (Claude Code + O 스킬)

요청을 서로 겹치지 않는 작업카드로 나눠 계획(JSON)을 만든다.

  • 유휴 시 쉬고, 부르면 최근 세션을 불러온다
  • 팀 대화로 카드에 답한다: o msg send
  • 끝나면 카드별 결과를 정리해 보고
→
중간 라우팅

O CLI

  • o dispatch 정책 검사 후 백그라운드 병렬 실행
  • 정책: 카드 8장·동시 6개·프로바이더별 상한·하루 60건, 한도 걸린 서비스 재사용 차단, 실행 파일·인자·계정 지정 금지
  • o msg 카드 사이 팀 대화 (정책 검사)
  • o usage 구독 한도를 각 CLI에 물어 저장
  • o status · o events · o stop
→

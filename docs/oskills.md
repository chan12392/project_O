# 프로젝트 스킬 선택

작업 폴더의 `.oskills/index.json`에 사용할 스킬을 등록한다. 목록은 로컬에서 검색하며, 작업 내용에 트리거가 포함된 스킬을 최대 5개 고른다. 작업에 `$skill-name`을 직접 쓰면 해당 스킬을 우선하고, 직접 지정한 스킬은 다섯 개가 넘어도 빠뜨리지 않는다.

```json
[
  { "name": "game-logic", "path": "game-logic/SKILL.md", "triggers": ["게임", "game"] },
  { "name": "ui", "path": "ui/SKILL.md", "triggers": ["화면", "UI"] }
]
```

경로는 `.oskills` 폴더 안의 `SKILL.md`여야 한다. 폴더 바깥으로 이어지는 링크와 잘못된 목록은 사용하지 않는다. O는 선택한 이름과 파일 경로를 전달하고 내용은 직접 읽지 않는다. 에이전트의 기본 지침과 안전 규칙은 스킬보다 우선한다. 스킬 목록이 없거나 맞는 트리거가 없으면 스킬을 추가하지 않는다.

스킬 파일과 인덱스는 프로젝트가 제공하는 자료이므로 신뢰할 수 있는 내용만 등록한다. 이 방식은 아직 통합 스킬 관리 화면이나 기존 CLI의 내장 스킬 목록 제거를 제공하지 않는다.

## O 하네스 블록

O 상태 폴더(`%LOCALAPPDATA%/project_O/harness`)의 `index.json`에는 같은 형식으로 로컬 지침 블록을 등록한다. `path`는 이 폴더 안의 `.md` 파일이다. 작업의 트리거에 맞는 블록을 최대 5개 고르고 각 블록의 내용은 4KB 이하여야 한다. 에이전트 CLI 자체의 기본 지침과 안전 경계는 유지되며 선택된 블록보다 우선한다. 목록과 블록은 신뢰할 수 있는 사용자가 관리한다.

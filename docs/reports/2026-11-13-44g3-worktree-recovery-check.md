# 실행 44g3의 워크트리 복구 확인

`project_O-worktrees/20261112-052641-44g3/1..7`의 미커밋 작업을 2026-11-13 현재 `younchan`에서 다시 대조했다. 복구 커밋 `1a1eb1d`는 현재 브랜치의 조상이며, 원래 실행의 일곱 카드가 이 커밋에서 복구되었다는 [기존 통합 보고서](2026-11-12-implementation-and-validation.md)와 코드·회귀 테스트가 일치한다. 이번 확인에서 추가로 반영해야 할 동작은 찾지 못했다. 이전 파일을 그대로 덮어쓰면 이후의 브랜치 기록·사용량 정산·보안 수정을 되돌릴 수 있다.

| 원본 | 작업과 현재 확인 |
|---|---|
| 1 | 예약 실행 표식과 이벤트·스냅샷: `mark_scheduled`, 이벤트 호환 및 예약 실행 회귀 테스트가 있다. |
| 2 | 날짜별 카드 횟수 제한 제거: 정책·실행기 검사와 시작 횟수 회귀 테스트가 있다. 미추적 `0044-card-count-policy.md`의 결정은 현재 [ADR-0045](../decisions/0045-sidebar-view-and-card-count.md)에 포함되어 있다. 현재 ADR-0044는 다른 결정이므로 원본 파일을 같은 번호로 추가하지 않는다. |
| 3 | 서비스 사용량·한도 표시: 현재 상태 표시와 사용량 회귀 테스트가 있다. 이후 사용률 경계 계산이 정밀도를 유지하도록 수정됐다. |
| 4 | 사이드바 그룹·정렬·필터: 보기 옵션 및 회귀 테스트가 있다. 현재 코드는 여기에 브랜치별 실행 묶음을 더한다. |
| 5 | Windows 프로젝트 경로 대소문자 테스트: 현재 파일과 원본이 같다. |
| 6 | 초안 이동과 에이전트 선택: #86·#107·#118 회귀 테스트와 구현이 있다. |
| 7 | 그래프 상태 전이와 노드 제한: #84·#101 회귀 테스트와 구현이 있으며 변경 파일 세 개가 현재 파일과 같다. |

Git 상태에서 확인된 변경은 54개 항목이다. 파일 전체 해시로 대조하면 복구 커밋에서 31개가 원본과 같고 22개는 다른 변경과 함께 통합됐거나 후속 조정됐다. 한 항목은 위 ADR 초안이다. 현재 `younchan`에서는 17개가 원본과 같고 36개는 다르며 ADR 초안 하나는 같은 경로에 없다. 파일이 다르다는 사실만으로 원래 동작이 미반영됐다고 판정하지 않고 예약 실행, 카드 정책, 사용량 표시, 사이드바, 초안 선택과 그래프의 구현·회귀 테스트를 확인했다.

검증: 관련 TypeScript 테스트 127개, Rust `policy` 28개와 `snapshot` 14개가 통과했다. 일회성 Rust 테스트에서 증분 컴파일을 끄지 않아 정리했던 증분 캐시가 251.7MiB 다시 생성됐다. 실제 UI와 외부 공급자는 이번에 실행하지 않았다.

일곱 원본 폴더와 Git 워크트리 등록은 그대로다. 워크트리 루트는 현재 정리 가드가 거부하며, 이전에 거부된 하위 캐시를 부모 이동이나 ACL 변경으로 우회하지 않았다. Git이 무시하는 파일의 개별 가치는 확인하지 않았다. 이 보고서는 원본 이동·삭제나 전체 파일의 완전한 의미상 동일성을 보증하지 않는다.

# ADR-0045: 프로젝트 보기 옵션·브랜치별 실행·하단 사용량과 카드 횟수 정책

- 상태: 채택
- 날짜: 2026-11-12
- 관련: ADR-0002, ADR-0004, ADR-0009, ADR-0013, ADR-0019, ADR-0033, ADR-0039

## 배경

프로젝트와 실행 기록이 늘면서 사용자 그룹만으로 목록을 정리하기 어렵다. 대표는 그룹화·정렬·예약 실행 필터·표시 개수 옵션과 실행 당시 Git 브랜치별 묶음을 요청했다. 하단의 날짜별 카드 횟수 대신 에이전트별 사용률과 초기화 시각을 확인하도록 바꾼다.

## 결정

- 프로젝트 제목 줄에 워크스페이스 옵션을 둔다. 그룹화는 없음·사용자 그룹·상태, 정렬은 최근 활동·이름·수동이다. 기본값은 사용자 그룹·최근 활동이다. test 묶음은 별도로 유지한다.
- 상태 그룹은 최근 실행 중 실패·답변 대기·한도에 걸린 카드가 있으면 확인 필요, 그 밖에 O 실행이 진행 중이면 진행 중, 나머지는 조용함이다. 기존 외부 세션을 O의 진행 중 실행으로 세지 않는다.
- 수동 정렬은 같은 섹션의 프로젝트 줄을 끌거나 프로젝트 메뉴의 위로·아래로 옮기기로 바꾼다. 경로 배열로 보존하며 새 프로젝트는 뒤에 붙인다. 없는 경로는 재등장할 때를 위해 남긴다.
- 자동화로 만든 실행 숨기기는 기본 꺼짐이다. 켜면 `run.scheduled === true`인 실행만 목록과 개수에서 제외한다. 필터로 프로젝트 자체를 없애지는 않는다.
- 실행 표시 개수는 프로젝트 전체에서 0·3·5·전체로 고르며 기본은 3이다. 초과분은 기존의 이전 실행 접기와 선택 표시 규칙을 따른다. 브랜치 묶음마다 표시 개수를 새로 할당하지 않는다.
- 옵션은 브라우저의 `project-o-sidebar-view` 키에 저장한다. 알려진 값만 읽고 잘못된 선택은 각 기본값으로 돌아간다. 저장 불가 환경에서는 현재 창에서만 유지한다.
- 프로젝트 아래 실행 줄은 기록된 이름 있는 Git 브랜치로 묶는다. 브랜치 정보는 실행 기록의 `run.branch { at, branch }` 이벤트에서 `RunView.branch?: string`으로 접는다. 과거 기록·비 Git 실행·이름 있는 브랜치가 없는 기록은 **브랜치 정보 없음**으로 표시한다. 현재 체크아웃 브랜치를 과거 실행에 추정해 붙이지 않는다. 기존 `run.start` 형태는 유지한다.
- 예약의 자동 분배로 시작된 실행은 실행 폴더에 `scheduled` 표식을 두고 러너의 `run.mode`에 `scheduled: true`를 기록한다. 일반 실행과 이전 기록은 필드를 생략한다. TS의 `RunView.scheduled?: boolean`으로 접어 필터와 연결한다. 사람이 나중에 직접 시작하거나 후속 실행한 기록을 자동으로 예약 실행이라 추정하지 않는다.
- 날짜별 카드 누적 횟수 제한은 정책 검사와 카드 시작 직전 예약에서 제거한다. 카드 수는 사용량 자체를 나타내지 않는다. 계획당 카드 수, 전체 동시 실행 6개, 서비스별 동시 실행, 자원 예약, 구독 한도·쿨다운과 하루 사용 예산은 유지한다. 시작 기록과 날짜별 통계도 남긴다.
- 상태 표시줄은 사용량 패널과 같은 CLI 사용량 창 및 최신 실행 스트림 quota를 읽는다. 에이전트 이름·5시간 사용률·초기화 시각, 주간 사용률·초기화 날짜는 툴팁과 접근성 이름에 담는다. 주간 창만 있거나 주간 한도가 소진됐으면 주간 값을 보인다. 모델 묶음이 여러 개면 아직 초기화되지 않은 창 중 가장 많이 쓴 묶음을 대표로 표시한다.
- 80%부터 경고, 한도 도달 시 위험 상태를 쓴다. 초기화 시각이 지난 기록은 새 사용률로 추정하지 않고 리셋됨·새로 읽기 필요로 표시한다. 사용량 조회가 없는 OpenCode·Devin은 실행 중 카드 수를 표시한다. 좁은 화면은 칩을 줄이거나 숨기되 실행 중 N/6 표시는 유지한다.

## 경계와 검증

호스트·PR 기준 분류, 브랜치 생성·병합 UI는 이 보기 옵션에 추가하지 않는다. 실행 당시 브랜치 기록의 생산은 Rust 실행 경로가 담당하고 화면은 기록을 소비한다. 사용량 수집·회계·폴백 정책은 이 표시 변경과 별개다.

예약/일반 실행의 이벤트 호환, 누적 75개 뒤의 계획·실행 허용과 기존 동시 실행 차단, 보기 옵션의 저장값·정렬·필터·상태·브랜치 묶음, 실제 Sidebar 렌더링의 표시 개수·이전 실행·선택을 검사한다. 복구한 #84·#101 Graph 상한/상태 전이, #86·#118 초안/에이전트 선택, #121 OS별 경로 대소문자 회귀도 통합 검사한다.

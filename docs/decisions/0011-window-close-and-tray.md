# ADR-0011: 창 닫기와 트레이

- 상태: 제안
- 날짜: 2026-11-02
- 승인: [ ] A  [ ] B

## 배경

대표 요청에 따라 창 닫기에서 트레이로 숨기기와 완전 종료를 선택할 수 있어야 한다. 실행 중인 에이전트를 확인하고 종료 전에 경고해야 한다. 앱이 닫힌 뒤 프로세스가 남은 현상의 원인은 아직 확인되지 않았다.

## 제안

- 창 닫기 동작은 물어보기, 트레이로 숨기기, 완전 종료 중에서 선택하고 설정에서 변경한다.
- 물어보기에서는 선택과 취소를 제공하고 원하는 경우 선택을 기억한다.
- 완전 종료 전 실행 중인 카드나 총괄이 있으면 경고하고 사용자가 취소할 수 있게 한다.
- 트레이 메뉴에 열기, 설정, 정보, 종료를 둔다. 트레이의 종료도 같은 경고를 거친다.
- 업데이트 설치를 위한 종료와 별도 패널 창, 기존 작업의 수명, 중복 실행 및 기존 창 복구를 함께 검증한다.

## 확인할 사항

종료 후 작업의 실제 수명과 기존 프로세스 잔존의 원인은 아직 미확인이다. 공용 앱 셸 변경이므로 양쪽 승인 후 구현·통합하고, 실제 창과 트레이에서 사용 경로를 검증한다.

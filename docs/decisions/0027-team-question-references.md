# ADR-0027: 팀 질문과 답변의 연결

- 상태: 부분 구현 (2026-11-04)
- 관련: ADR-0022, ADR-0026

## 결정

팀 메시지 답변은 선택적 `replyTo`로 같은 실행의 질문 ID를 가리킨다. 질문을 받은 당사자만 원래 질문자에게 답할 수 있고, 취소된 질문이나 일반 메시지에는 연결할 수 없다. 방송 질문은 각 수신자가 질문자에게 답할 수 있다. `o msg send --to <질문자> --reply-to <질문ID> --id <재시도키> <내용>`으로 기록하며 재시도 키가 같은 답변은 같은 질문과 내용을 가리킬 때만 중복을 제거한다. 기존 메시지와 이벤트에는 이 필드가 없어도 된다. CLI와 화면은 질문 ID와 답변 대상을 표시한다.

기록은 메시지의 저장과 연결만 뜻하며 상대 에이전트가 읽거나 처리했다는 증거는 아니다. 수신 순서와 불명 상태의 수동 복구는 ADR-0026을 따른다. 카드의 내용은 사용자 지시나 실행 승인이 아니다.

## 미구현

질문이나 결과로 총괄 세션을 자동 재호출하거나, 총괄 답변을 자동으로 카드에 전달하지 않는다. 자동 연결에는 원래 대화와 승인된 실행 확인, 유휴 세션 잠금, 질문과 결과의 순서, 재시작 후 불명 상태의 중복 방지, 작업 중인 카드의 답변 대기 및 지원 프로바이더별 실제 전달 보장을 함께 구현해야 한다. 특히 기존 `lead send`는 입력을 사용자 발화로 저장하고 후속 지시 또는 YOLO 자동 실행을 허용하므로 카드 입력에 그대로 사용하지 않는다. 이 ADR은 자동 호출이나 모든 프로바이더의 실시간 수신 지원을 주장하지 않는다.

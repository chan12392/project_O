# ADR-0044: 날짜별 카드 수 제한 제거

- 상태: 채택 (대표 요청)
- 날짜: 2026-11-12
- 관련: ADR-0002(시작 직전 검사), ADR-0004(하루 사용 예산), ADR-0013(예산 스위치)
- 코드: `crates/o-core/src/policy.rs`, `run/leases.rs`, `run/runner.rs`, `src/core/limits.ts`

## 배경

카드 수는 서비스의 실제 사용량과 다르다. 날짜별 누적 카드 수로 계획과 카드 시작을 막던 제한을 제거하고, 동시 실행과 구독 사용량에 따른 제어를 유지한다. 공용 정책 상수와 실행기 경계가 바뀌므로 ADR로 남긴다.

## 결정

- 계획 검사와 실행기 슬롯 획득에서 날짜별 누적 카드 수를 제한하지 않는다. 이 사유로 대기 카드를 실패 처리하는 경로도 제거한다.
- 전체 동시 실행 6개와 서비스별 동시 실행 상한, 계획당 카드 수, 쿨다운 및 서비스 재사용 차단은 유지한다.
- ADR-0004·0013의 하루 사용 예산과 시작 직전 예산 검사, effort 조절, 예산 스위치는 유지한다.
- 날짜별 시작 기록은 통계 조회에 계속 사용하되 정책 검사 문맥에서는 제거한다. 데이터베이스 스키마나 기존 기록은 바꾸지 않는다.
- 화면의 정책 상수 사본과 설정 안내, 관련 설계 문서도 같은 정책을 표시한다.

## 확인과 되돌리기

- 누적 시작 기록이 많아도 카드가 시작되고, 동시에 분배한 실행도 정상 완료되는지 회귀 테스트로 확인한다. 기존 동시 실행·예산 테스트도 유지한다.
- 되돌릴 때는 계획 검사와 슬롯 획득을 함께 복원하고 화면 상수와 문구도 맞춘다. 시작 기록을 보존하므로 데이터 이전은 필요 없다.

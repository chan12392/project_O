# ADR-0022: 분배한 에이전트 세션의 후속 작업

- 상태: 적용
- 날짜: 2026-11-03

사용자가 한 번 분배한 작업은 에이전트 화면에서 직접 이어서 지시할 수 있다. 총괄 대화에서도 기존 작업의 수정을 요청하면 총괄이 작업 ID별 후속 지시를 제안하고 O가 바로 접수한다. 새 작업은 `새 설계`로 별도 대화를 시작해 이전과 같이 계획을 확인하고 분배한다.

후속 지시는 O가 저장한 실행·카드에서만 에이전트, 프로필, 세션과 원래 격리 폴더를 찾는다. 실행 중이면 해당 카드가 끝날 때까지 슬롯을 차지하지 않고 기다린다. 같은 원래 카드에 대기·실행 중인 후속 작업은 한 번에 하나이며 중복 요청은 실패로 남는다. 작업 시작 전 정책·사용량과 폴더를 다시 확인한다. 후속 작업의 권한은 일반 모드이고, 에이전트가 O의 후속 실행 명령을 직접 호출할 수 없다. OpenCode는 없는 세션 ID로 새 세션을 만들 수 있으므로 공식 목록에서 해당 세션과 폴더가 확인될 때만 시작한다.

후속 실행 기록은 실행기를 띄우기 전에 남긴다. 실행기와 카드 프로세스가 모두 사라진 미완료 실행은 목록에서 중단된 실패로 표시하고 기존 세션에 다시 보낼 수 있다. 실행기 시작 전 비정상 종료는 최대 2분의 시작 유예 뒤 확인한다. 실패 표시는 원본 이벤트 파일을 수정하지 않는다.

총괄의 출력은 신뢰하지 않는다. 후속 블록이 "실행" 없이 접수되는 것은 이미 승인·분배한 작업의 연장이기 때문이다. 그래서 현재 대화에서 실제 분배한 실행(과 그 후속 실행)만 참조할 수 있고, 분배 전이거나 "새 설계"로 대화가 바뀐 뒤에는 보내지 않는다. 원래 카드가 중지되면 그 뒤에 대기하던 후속 지시도 취소된다. 후속 블록은 정책 차단과 실행 실패를 대화에 표시한다. 총괄은 사용자의 요청이 기존 작업을 수정하려는 것인지 판단하므로 오판 가능성은 남는다. 사용자는 에이전트의 실제 진행 상태를 확인할 수 있다.

화면은 원래 팀과 후속 대화를 같은 창에 모으되 최근 실행 목록에서 찾을 수 있는 이력만 보여 준다. 외부에서 가져온 Claude 하위 에이전트 기록은 공식적으로 재개하는 경로를 확인하지 못해 읽기 전용이다. Antigravity 차단은 ADR-0020을 유지한다.

# ADR-0010: 실행 설정 스위치 하나로 묶기

- 상태: 대체됨(ADR-0013)
- 날짜: 2026-11-02
- 관련: ADR-0004(하루 사용 예산), ADR-0005(공유 컨텍스트), ADR-0008(총괄), ADR-0013

## 배경

대표 요청으로 실행 설정을 켜고 끄는 스위치를 만들었다. 기존의 깨끗한 프로필 설정은 유지하면서 카드 실행과 총괄, 검토에 같은 선택을 전달했다.

## 당시 결정

- 켜짐은 깨끗한 프로필, 이전 작업 컨텍스트 주입, 하루 예산에 따른 effort 낮춤을 함께 썼다.
- 꺼짐은 평소 프로필과 선택한 effort를 쓰고 컨텍스트를 주입하지 않았다.
- 하루 예산에 따른 실행 차단과 보안 규칙은 두 경우 모두 적용했다.
- 앱은 기존의 깨끗한 프로필 설정값(`clean`)을 선택값으로 썼다.

## 대체

대표가 원한 것은 하루 사용 예산을 켜고 끄는 것이었다. ADR-0013에서 스위치를 "project_O 프로필 사용"(프로필만)과 "하루 사용 예산"(차단·effort 낮춤)으로 나눴다. 이 ADR의 CLI 플래그는 릴리스되지 않아 없앴고, 공유 컨텍스트는 다시 항상 켜진다(`--no-context`로만 끔).

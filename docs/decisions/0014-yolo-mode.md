# ADR-0014: YOLO 실행과 자동 실행 제한

- 상태: 채택 (윤찬 결정)
- 관련: ADR-0002, ADR-0008, ADR-0013

YOLO는 기본적으로 꺼져 있다. 켜면 총괄과 카드에 각 CLI의 공식 권한 우회 옵션을 전달하고 총괄도 파일을 수정하거나 명령을 실행할 수 있다. 앱에서 켤 때 확인을 받으며 입력창에 YOLO를 표시한다. 실행마다 CLI의 `--mode yolo|normal`로 선택할 수도 있고 실행 기록에 모드를 남긴다.

하루 사용 예산도 켜져 있고 정책 검사를 통과한 계획만 자동 실행한다. 기본 한도는 카드 3장, 대화별 시간당 2회, 같은 계획 30분 재실행 금지이며 기존 실행이 진행 중이면 기다린다. 설정에서 카드와 시간당 횟수는 1–6, 중복 대기는 10–120분으로 조정한다. 자동 실행 판단을 `lead.autorun`에 기록하고 실행하지 않는 이유를 계획에 표시한다.

총괄과 카드에는 O가 실행 표식을 주며 O CLI와 Claude 거부 규칙, Antigravity 거부 규칙, O 가드 훅이 직접 작업 전달을 제한한다. Claude YOLO에는 실패 시 차단하는 O 훅을 전달한다. Codex와 Antigravity의 YOLO에서 동일한 훅 적용은 확인되지 않았다.

이 제한은 OS 격리가 아니다. 같은 Windows 사용자 권한에서는 에이전트가 환경변수를 제거하거나 별도 프로세스를 이용해 제한을 우회할 수 있다. 이런 한계는 설정 화면에도 표시한다. 사용자 요청에 따라 OS 계정 격리는 이번 범위에 넣지 않는다.

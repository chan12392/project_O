# ADR-0016: Devin 작업카드 연결

- 상태: 채택
- Devin CLI는 `devin -p`로 작업카드에만 연결한다. 총괄은 읽기 전용 동작과 재개가 검증된 ACP 연결을 마련한 뒤 지원한다.
- 기본 권한은 작업 폴더 편집만 승인하며 셸은 대화형 승인이 필요하다. YOLO에서는 공식 `--permission-mode dangerous`를 쓴다. 작업 폴더 신뢰 검사는 해제하지 않는다.
- 종료 후 `--export` 기록에서 도구 단계와 사용량을 읽고 표준 출력에서 결과를 얻는다. 기록 파일은 일반 파일만 읽으며 링크와 과도한 크기를 거부한다.
- Devin 설정 폴더를 독립 프로필로 옮길 수 없으므로 project_O 프로필을 켠 계획은 명확한 사유와 함께 거부한다. 평소 프로필을 쓸 때 개인 훅·설정은 Devin이 적용한다.
- 구독 사용량 창을 조회할 수 없어 하루 예산은 적용되지 않는다. LIMITS의 Devin 동시 실행 상한은 2이며 전체 동시·일일 상한은 그대로 적용한다.
- 동일한 Windows 사용자 권한에서 실행되므로 에이전트가 O의 환경 표식을 지우거나 별도 프로세스를 실행하는 일을 운영체제로 격리하지 않는다(ADR-0014).

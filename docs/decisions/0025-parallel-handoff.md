# ADR-0025: 병렬 작업의 결과 보존과 인계 (부분 구현)

상태: 진행 중. 코드 변경 인계와 충돌 관리는 아직 구현되지 않았다.

선행 카드의 결과는 참고 데이터이며 후속 카드의 권한이나 지시가 아니다. 현재 실행기는 결과를 1,000자에서 자르지 않고 JSON으로 직렬화해 전달한다. 전체 직렬화 결과가 12,000바이트를 넘거나 완료 기록을 찾지 못하면 원문 일부를 전달하는 대신 후속 카드를 실패 처리한다. 제한을 넘는 결과를 안전하게 읽을 수 있는 원문 경로와 접근 권한은 아직 구현되지 않았다.

카드의 표준 출력은 바이트 그대로 기록한다. 표준 출력 또는 오류 로그의 기록 실패는 카드 실패로 취급하며, 실행 도중 오류가 생기면 프로세스 종료를 시도한다. 프로세스가 살아 있는 것으로 확인되면 슬롯과 활성 표시를 되돌리지 않고, 종료 이벤트가 있더라도 해당 카드의 세션을 이어서 사용하지 않는다.

분리된 폴더 사이의 코드 변경은 아직 자동으로 전달하지 않는다. 기준 커밋과 변경 범위 확인, 추가·삭제·바이너리 합성, 충돌과 사람의 변경 보호, 비 Git 및 무시 파일 정책, 외부 자원 충돌과 중단 후 복구는 별도 구현과 검증이 필요하다. 작업공간 분리는 외부 자원의 OS 격리를 뜻하지 않는다.

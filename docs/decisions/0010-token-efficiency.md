# ADR-0010: 토큰 효율 선택

- 상태: 채택 (대표 요청으로 구현)
- 날짜: 2026-11-02
- 관련: ADR-0004(일일 예산), ADR-0005(공유 컨텍스트), ADR-0008(총괄)

## 배경

대표 요청에 따라 토큰 절감 동작을 켜거나 끌 수 있어야 한다. 기존의 깨끗한 프로필 설정은 유지하면서 카드 실행과 총괄, 검토에 같은 선택을 전달한다.

## 제안

- 켜짐은 깨끗한 프로필, 이전 작업 컨텍스트 주입, 예산에 따른 노력 수준 하향을 사용한다.
- 꺼짐은 평소 프로필과 선택한 노력 수준을 사용하고 컨텍스트를 주입하지 않는다.
- 일일 예산에 따른 실행 차단과 보안 규칙은 두 경우 모두 적용한다.
- 기존 앱의 깨끗한 프로필 설정값을 선택값으로 유지한다. CLI는 `--efficiency on|off`를 받는다.
- 실행 기록에 선택값을 남기고 이전 기록은 그대로 읽는다. PR 검토에는 별도 컨텍스트를 주입하지 않는다.

## 확인할 사항

공용 실행 기록과 총괄 세션에 영향을 주므로 변경 전 실행 기록과 실행 중인 에이전트의 호환성을 확인한다.

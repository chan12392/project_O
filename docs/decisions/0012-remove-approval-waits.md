# ADR-0012: 승인 대기 없는 작업 흐름

- 상태: 채택 (대표 요청)
- 날짜: 2026-11-02
- 관련: ADR-0003(브랜치 흐름), ADR-0006(PR 교차 검토)

## 결정

공용 경계 변경은 ADR로 기록하되 양쪽의 별도 승인 대기 없이 진행한다. PR 교차 검토도 필요에 따라 선택한다. 기존 ADR에 적힌 승인 체크는 당시 기록이며, 미완료 체크로 작업이나 병합을 막지 않는다.

브랜치별 병합 흐름, CI 검사, 보안 정책과 사용자의 명시적인 실행·권한 확인은 유지한다. 대표의 에이전트는 대표가 지시한 범위에서 병합할 수 있다.

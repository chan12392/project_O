# ADR-0002: 보안 검토 후 정책 경계 강화

- 상태: 제안 (기존 B 승인 대기는 ADR-0012에서 해제)
- 날짜: 2026-11-02
- 승인: [x] A  [ ] B
- 관련: `AGENTS.md` 프로바이더 정책 자동 차단, `docs/DESIGN.md` §8

## 배경

2026-11-02 전체 보안 검토에서 카드(에이전트 CLI)가 사람 승인 없이 정책 경계 밖에 영향을 줄 수 있는 경로가 나왔다. 규칙(`src/guard/rules.ts`)과 계획 검사(`src/core/policy.ts`)는 공용 경계라 이 ADR로 남긴다. 상한 값(`LIMITS`)은 바꾸지 않았다.

## 결정

막는 쪽으로만 바꾼다. 허용 범위를 넓힌 것은 없다.

| 경로 | 문제 | 바꾼 것 |
|---|---|---|
| `o msg read --as <경로>` | 카드가 실행 폴더 밖 파일을 덮어쓸 수 있었다(Claude 카드는 `o msg *`가 사전 허용) | `--as`는 그 실행의 카드나 `lead`만, 실행 id는 영문·숫자·`-`·`_`만 받는다 |
| 카드의 신원 | 카드가 `--as lead`·`--run <다른 실행>`으로 총괄을 사칭하거나 다른 실행에 끼어들 수 있었다. 줄바꿈으로 다른 발신자를 흉내 낼 수 있었다 | 카드 안(`O_CARD_ID`)에서는 러너가 정한 실행·카드만 쓴다. 읽을 때 메시지는 한 줄로 보인다 |
| `plan.project` | 작업 폴더로 O 상태 폴더·홈 폴더·드라이브 루트를 지정하면 카드가 상한·쿨다운 기록이나 CLI 설정을 고칠 수 있었다 | O 상태 폴더 안이거나, 그것을 품거나, 홈 폴더 자체·그 위인 폴더는 거부(`protected-project`) |
| `o _run` | 손으로 만든 plan.json으로 정책 검사를 건너뛸 수 있었다 | 실행 직전에 정책을 다시 검사하고, 실패해도 `run.end failed`를 남긴다 |
| npm `.cmd` 설치본 실행 | `shell:true`로 cmd.exe를 거쳐 인자가 쪼개지거나 주입될 수 있었다 | 셸을 쓰지 않는다. `.cmd`가 가리키는 스크립트를 node로 직접 실행하고, 못 읽으면 실행하지 않는다 |
| 하루 실행 상한 | 연달아 dispatch한 계획이 같은 숫자를 보고 모두 통과했다 | 카드를 시작하기 직전에도 하루 상한을 확인한다 |
| 거울 읽기 전용 | 다른 폴더에서 `git -C <거울>`·절대 경로로 고칠 수 있었고, `&`·`$(…)`·`` ` ``·`rg --pre`·`git grep -O`·`--output`·`grafly` 쓰기 명령으로 허용 목록을 우회할 수 있었다 | 명령이 거울 경로를 가리켜도 같은 규칙을 적용하고, 그 문법·옵션은 거울에서 거부한다. grafly는 조회 명령만 허용 |
| 에이전트 훅 | NotebookEdit 경로를 보지 않았고, 입력을 못 읽거나 예외가 나면 통과시켰다. Read·Grep·Glob으로 인증 파일을 열 수 있었다 | `notebook_path`도 검사하고, 실패하면 막는다(exit 2). Claude 훅 matcher에 Read·Grep·Glob을 넣어 인증 파일 열람을 막는다 |
| 거울 자동 동기화 | 5분마다 사람이 보지 않는 상태에서 저장소 git 훅이 실행될 수 있었다 | 동기화의 git 호출은 저장소 훅을 쓰지 않는다 |
| 개발 서버 API | 다른 localhost 포트의 페이지가 실행 기록을 읽을 수 있었다 | `/api`는 같은 출처 요청만 받는다(Host·Origin 검사) |
| CI | 토큰 권한이 기본값이었다 | `permissions: contents: read`, 타입 검사 단계 추가 |

## 남은 위험 (이번에 막지 않음)

- Codex 카드는 팀 대화(`o msg`)를 위해 실행 폴더 쓰기 권한(`--add-dir`)이 있어, 원하면 `events.jsonl`을 직접 고칠 수 있다. 팀 대화 기록 방식을 바꿔야 해서 별도 결정이 필요하다.
- 카드 CLI가 인증 파일을 읽는 것을 기술적으로 막는 장벽은 각 CLI의 샌드박스에 달려 있다(우리 훅은 이 저장소에서 일하는 에이전트에만 걸린다).
- 커밋 작성자 이메일이 초기 커밋 19개에 남아 있다. 비공개 저장소라 이력은 다시 쓰지 않았다. 공개 전에 정리한다.
- CI 액션은 태그(`@v4`)로 고정돼 있다.
